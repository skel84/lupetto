About this security data. Fixes come from Wolfi’s public security feed. It isn’t a full vulnerability scan.What this meansHide
  • Fixed issues only. Lupetto lists advisories that Wolfi has already fixed in a newer package. Issues without a fix yet are not listed, so “none found” does not mean “no vulnerabilities”.
  • Wolfi packages only. Software added outside Wolfi packages is not covered.
  • The feed is not signed. It is fetched over HTTPS from packages.wolfi.dev (unlike the package index, whose signature is verified).
  • Severity comes from NVD (CVSS) or GitHub/OSV advisories. Newly published advisories may show Unknown until they are scored; severity never changes a verdict.
