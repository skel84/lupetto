# Lupetto v0.5.1 release notes

v0.5.1 is a security update. The CLI, Explorer, build records, the status document, and the products-file format behave as in v0.5.0. The [changelog](../../CHANGELOG.md#v051-2026-11-26) lists every change.

## Security

- **Go 1.27.4.** Go 1.27.1's standard library had reachable vulnerabilities in `net/http` (including HTTP/2), `crypto/tls`, `crypto/x509`, `html/template`, `net/textproto`, and `os`.
- **Go dependencies.** `github.com/andybalholm/brotli` v1.2.7 (GO-2026-6888, CVE-2026-111497, listed in CISA KEV), `github.com/klauspost/compress` v1.20.2 (GO-2026-6865), `github.com/containerd/containerd/v2` v2.4.2 (GO-2026-7007), and OpenTelemetry v1.47.0 (GO-2026-6974).
- **Container base.** The combined container moves to a current `cgr.dev/chainguard/wolfi-base` digest, which carries fixed Brotli libraries. apko stays at exactly 1.4.5, which the CLI requires, and `docker-cli` 28.5.0 and Cosign v3.1.3 stay pinned, so findings in those binaries remain.

`govulncheck ./...` still reports GO-2026-6905 (a panic on a negative member size in `github.com/blakesmith/ar`), which has no fixed version. The module comes in through Syft's Debian cataloger in Explorer's scanner; govulncheck reaches it only through an `io.Reader` interface call in `vulnscan.OpenStore`.

## Upgrading from v0.5.0

Replace the CLI, or the combined container. Nothing is rebuilt.
