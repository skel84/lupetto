# Implementation checklist

[Documentation home](../README.md) · [Decisions](decisions.md) · [Verification](verification.md)

This is the single implementation checklist. The standalone CLI, tool check, live signed-index discovery, generic local build, per-architecture SPDX/lock identity validation, default local Docker loading/explicit no-load, registry publication, and Cosign signing/signed SPDX attestation are complete within the scoped verified local path. Real local HTTP/offline signing, verification, negative and partial-failure scenarios, and the combined focused race-enabled/full Go test gates passed; production HTTPS/TUF/public-Rekor verification passed against one authorized Harbor registry ([production Harbor evidence](verification.md#production-harbor-registry-and-public-rekor-verification-2026-10-02)). Persistent catalog ingestion remains deferred. Mark an item complete only after its observable behavior is verified; record the command/result or evidence reference beside it. Track blockers beside the affected item and design choices in the decision record, rather than creating a second status list.

The CLI and Explorer are separate workstreams. The CLI can ship after its implementation and release checks below; it does not wait for Explorer. Explorer remains part of the full compatibility scope, but its product/repository/module packaging is undecided.

**Approved priority:** registry publication, Cosign image signing, and signed SPDX attestation are implemented and verified within the local scope recorded below, using the current live signed-index exact-build path. This does not complete the separate production-verification acceptance gate. Persistent catalog/snapshot-history work is deferred and is not a prerequisite for those stages or the standalone CLI release. Per-build snapshot/lock/evidence retention remains mandatory; catalog and Explorer remain in full scope. See the [decision record](decisions.md#publication-first-roadmap-user-approved).
